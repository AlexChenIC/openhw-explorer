## Headquarters

The filter uses the listed entity's documented headquarters, not nationality, founders, investor location or service markets. src/data/industry-headquarters.ts contains a first-party source for each confirmed value.

Every listing now passes through the same mapping. Missing evidence yields a null headquartersCountry and an explicit unconfirmed group. Earlier country/region guesses are not silently upgraded into verified headquarters. They can be restored individually after sourcing.

This pass confirms 21 headquarters; 28 other active entities remain available under All and HQ unconfirmed. This deliberately leaves a visible evidence gap rather than assigning a parent company or one of several offices as headquarters. A company's global availability must be checked with its own sales contacts; the filter is not a list of countries it serves.
